# React + Remotion Showreel

15-секундный ролик (1920×1080, 30 fps), полностью собранный из React-компонентов.

Сцены: прыгающий заголовок на spring-анимации → редактор кода с «печатью» и живым превью →
анимированный бар-чарт из данных → React-атом с орбитальным конфетти.

```bash
npm install
npx remotion studio src/index.ts          # превью в браузере
npx remotion render src/index.ts Showreel out/showreel.mp4
```
